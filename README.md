# Rahul Bhardwaj — Portfolio

**Live:** https://portfolio-dun-beta-58.vercel.app/

Personal portfolio site built to showcase backend engineering work — real debugging stories, architecture decisions, and measurable outcomes.

## Pages

- `/` — Homepage with bento grid layout
- `/case-studies/billing` — 6 min → 11s billing job autopsy
- `/case-studies/cibil` — ₹30L/yr bureau integration savings
- `/case-studies/eks-migration` — 23 services ECS → EKS zero-downtime migration

## Stack

- **Framework:** Next.js 15 (App Router, fully static)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + custom CSS design system (dark mode, teal accent)
- **Animation:** Framer Motion, Lenis smooth scroll
- **Fonts:** Geist + JetBrains Mono

## Easter Eggs

- Konami code → sudo mode
- XP bar fills on scroll
- 7 unlockable achievements
- Incident response mini-game behind the "DO NOT PRESS" button

## Local Dev

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
